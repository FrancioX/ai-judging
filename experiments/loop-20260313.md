## Iteration 6 — Phase A Conflict-Resolution Refinements (all rejected)

**Date:** 2026-03-13
**Goal:** Further reduce Gabin Leonard's 58.6px error by fixing the root cause: the Phase A OF trace seeds from the wrong person (bystander) then high-confidence conflicts consistently pick the bystander (median error only 2.3px but ~11% of frames have 300-600px ID-switch errors).

**Approaches tried (all on 6-video set: mini + Jordan + Gabin):**

1. **Single-candidate-only OF re-anchoring**: only re-anchor the pre-built OF trace at frames with exactly 1 candidate. → Flat (0.0px change). Root cause: seed selection itself is wrong, not re-anchoring policy.

2. **Longest-track seed for OF trace** (kept, neutral): use the track with most detections rather than highest-score as the OF trace seed. → Flat (0.0px). Kept since more principled and no regression.

3. **conflict_of_multiplier=0.0**: eliminate OF weight entirely during conflicts. → Gabin +2.9px worse. Removing OF makes quality+continuity dominate, which also picks bystander.

4. **Identity guard enabled (max_jump=150px, 200px)**: OF-based post-Phase-A filter rejecting detections jumping >N px. → Gabin +2.6px, Quentin +2.8px worse. Aerial phases create legitimate large jumps.

5. **conflict_velocity_multiplier sweep [3.0, 5.0]**: boost velocity consistency weight during conflicts (300px bystander jump should score ~0). → Gabin +0.7px / +3.7px worse. Self-reinforcing feedback: once tracker switches to bystander, velocity history also tracks bystander.

**Conclusion:** All approaches rejected. Gabin's Phase A failure is a self-reinforcing feedback loop (wrong seed → wrong OF trace → wrong velocity history → wrong conflict decisions). Requires ReID or pose plausibility (Experiments A/B) to break the loop. Code changes: `conflict_velocity_multiplier` param added to infrastructure but left at 1.0; longest-track seed kept.

**Retained changes from Iter 6:**
- Longest-track OF seed (neutral, more principled)
- `conflict_velocity_multiplier=1.0` wired through (default, no effect)

## Iteration 7 — Kalman Segment Re-init at Long Gap Boundaries (OC-SORT style)

**Date:** 2026-03-14
**Goal:** Prevent the RTS backward smoother from propagating incorrect gap-fill trajectories backward into pre-gap detected frames, by re-initialising the Kalman state at detected frames following long gap-fill sequences.

**Implementation:** Added `kalman_reinit_gap: int = 0` parameter to `_smooth_bboxes_velocity_aware()`. In the forward pass, when a detected frame follows ≥ N consecutive interpolated frames, `x_pred` and `P_pred` are overwritten from the current detection (hermite seed from measurement + OF velocity). In the RTS backward pass, frames marked as segment boundaries get `G = 0` — RTS does not propagate backward across gap boundaries. Wired through `track_skier()`, `pipeline.py`, and `config.yaml`. Tested with `kalman_reinit_gap=20`.

**Mini-set results (kalman_reinit_gap=20 vs kalman_reinit_gap=0):**

| Video | Baseline err | New err | Δ err | HOTA |
|-------|:-----------:|:-------:|:-----:|:----:|
| Arno | 47.9 | 47.9 | +0.0 | 0.734 |
| Andreas | 8.7 | 8.7 | +0.0 | 0.932 |
| Jonatan | 4.6 | 4.6 | +0.0 | 0.955 |
| Quentin | 47.8 | 47.8 | +0.0 | 0.753 |

**Conclusion:** Null result — no improvement despite firing 7 re-inits for Arno (gaps of 323/47/46/45/40/31/26 frames). Root cause: the error is in the **gap-fill positions themselves** (Phase B OF drift), not in the Kalman smoother contaminating detected frames. The Kalman already uses R_interp=40.0 vs R_det=4.0 (10× noise ratio), so RTS backward propagation across gaps is already largely suppressed. Rejecting the re-init change makes no difference to output. **Rejected — config kept at kalman_reinit_gap=0. Code infrastructure retained (isolated, zero cost with gap=0).**

## Iteration 9 — Phase A HSV Color Histogram Appearance Similarity

**Date:** 2026-03-14
**Goal:** Use HSV color histogram similarity between candidate crops and a reference skier histogram (accumulated from single-candidate frames) as a discriminative Phase A signal — skier and bystanders should have different clothing colors.

**Implementation:** Added `w_color: float = 0.0` parameter to `_resolve_merge_conflicts()` and `track_skier()`. In `_score_pass()`, accumulates reference HSV histogram (18H×16S bins, normalized) from the first 30 single-candidate frames. For conflict frames, computes HSV histogram for each candidate crop, compares to reference using `cv2.compareHist(HISTCMP_CORREL)`, maps [-1,1]→[0,1]. Frame images loaded on-demand with local `_color_frame_cache`. Wired through config.yaml as `w_color: 0.5`.

**Merge threshold sweep (fast reject in same iteration):**  `merge_threshold_high: 0.7` → Andreas 8.7→65.4px immediate regression. Reverted.

**Color histogram results (Jordan + Gabin, w_color=0.5 and 2.0):**

|-------|:-----------:|:-----------:|:-----------:|
| Jordan | 42.6 | 42.6 | — |

**Conclusion:** Null result. Root cause: freeride competition bystanders are other athletes wearing similar ski/snowboard gear. Simple color histograms provide no discriminative power in this domain — requires a trained appearance embedding (ReID) to discriminate. **Rejected — config reset to w_color=0.0. ## Iteration 8 — Phase A Bbox Area Consistency Scoring

**Date:** 2026-03-14
**Goal:** Add bbox area consistency as a Phase A scoring signal — bystanders may be smaller/larger than the primary skier, and rewarding candidates whose area matches the historical skier bbox area could help disambiguate conflicts.

**Implementation:** Added `w_size: float = 0.0` parameter to `_resolve_merge_conflicts()` and `track_skier()`. In `_score_pass()`, maintains `area_history: deque[float]` (maxlen=50) from single-candidate frames. For multi-candidate frames, computes `size_score = exp(-0.5 * log(area/mean_area)² / 0.5²)` — Gaussian in log-ratio space (sigma=0.5). Added `w_size * size_score` to combined scorer. Tested w_size=0.3 (mini set) and w_size=1.0 (Jordan + Gabin directly).

**Results (mini set + Jordan + Gabin):**

|-------|:-----------:|:----------:|:----------:|
| Arno | 47.9 | 47.9 | — |

| Jonatan | 4.6 | 4.6 | — |
| Quentin | 47.8 | 47.8 | — |
| Jordan | 42.6 | 42.6 | 42.6 |
| Gabin | 58.5 | 58.5 | 58.5 |

**Conclusion:** Null result at all tested weights. Root cause: bystanders in freeride competitions are other athletes at similar distances — their bbox areas are nearly identical to the target skier. The size signal provides no discriminative power. **Rejected — config reset to w_size=0.0. Code infrastructure retained (isolated, zero cost when disabled).**
